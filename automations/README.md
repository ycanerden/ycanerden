# Automations

This folder is the company ops team. You do not run them from here. You paste them into the [Automations tab](https://cursor.com/automations).

Start with [`SETUP.md`](./SETUP.md).

| File | Job |
| --- | --- |
| `daily-content.md` | Morning LinkedIn + X drafts |
| `opportunity-radar.md` | Who to reply to today |
| `weekly-gtm.md` | Sunday operator memo |
| `ship-to-post.md` | Repo ship → posts |
| `engage.md` | X replies (draft by default) |

Rules live in [`../AGENTS.md`](../AGENTS.md).
